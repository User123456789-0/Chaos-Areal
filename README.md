## Requirements

- Minecraft Java Edition 26.3
- [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft 26.3
- [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=26.3) for Minecraft 26.3

Put both the Chaos Arsenal JAR and the Fabric API JAR in your `mods` folder.
